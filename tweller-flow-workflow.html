Step-by-Step Workflow

1
RAW Photos Imported
booked → imported

Trigger: Photos appear in the session folder

Reads from:RAWS-FOR AUTOMATION\{Code} - {Client}\
Detects:Any RAW or image files (.cr3, .nef, .arw, .jpg, etc.)
What happens:Stage advances to Imported — photo count sent to WordPress
2
Culling Started (Green Labels)
imported → culling

Trigger: Green-labeled photos detected in Lightroom XMP sidecars

Reads from:RAWS-FOR AUTOMATION\{Code} - {Client}\ (reads .xmp files)
Detects:xmp:Label="Green" in XMP sidecar files
What happens:Stage advances to Culling — green count reported
3
Culling Complete
culling → culled

Trigger: Green count unchanged for 2 minutes

Wait time:120 seconds (cullStableSeconds)
What happens:Stage advances to Culled + green-labeled RAWs copied:

RAWS-FOR AUTOMATION\{Code} - {Client}\*.cr3 + *.xmp
   ↓ copies green-labeled RAWs + XMP sidecars
CULLED\{Code} - {Client}-FOR-IMAGEN\

4
Auto-Advance to Editing
culled → editing

Trigger: Automatic after 30 seconds in "culled" stage

Wait time:30 seconds (editAutoAdvanceSeconds)
What happens:Stage advances to Editing + exports folder auto-created

You upload the FOR-IMAGEN folder to Imagen AI at this point.

5
Imagen Edits Detected
editing → edited

Trigger: Develop settings appear in XMP sidecars (80%+ photos edited, stable 2 min)

Reads from:CULLED\{Code} - {Client}-FOR-IMAGEN\ (CULLED folder)
Detects:Camera Raw settings: ToneCurve, Exposure, Contrast, Highlights, Shadows, etc. (2+ indicators)
Wait time:120 seconds (imagenStableSeconds) + 80% edit threshold
What happens:Stage advances to Edited + edited RAWs copied to Lightroom:

CULLED\{Code} - {Client}-FOR-IMAGEN\*.cr3 + *.xmp
   ↓ copies edited RAWs + XMP with develop settings
LR-AUTO-IMPORT\

Lightroom auto-imports these, then you export JPGs.

6
Exports Detected
edited → exporting → exported

Trigger: JPG/PNG files appear in exports folder

Reads from:EXPORTS-FOR AUTOMATION\{Code} - {Client}-Exports\
Detects:.jpg, .jpeg, .png, .webp, .tif, .tiff files
Wait time:60 seconds (exportStableSeconds) for file count to stabilize
What happens:Stage advances to Exported — ready for upload
7
Auto-Upload to WordPress Gallery
exported → uploading → uploaded

Trigger: Exports stable + auto-upload enabled

Reads from:EXPORTS-FOR AUTOMATION\{Code} - {Client}-Exports\
Uploads to:WordPress gallery via REST API (2s between each photo, 3 retries)
Skips:Photos already on server (deduplication check)
What happens:Each JPG uploaded, thumbnails generated server-side, stored in wp-content/uploads/tweller-gallery/{code}/
8
Gallery Delivered
uploaded → delivered

Trigger: All photos uploaded successfully

What happens:Stage advances to Delivered — client notification email sent automatically
Client gets:Email with gallery link: twellerstudios.com/session-tracker/?code={CODE}#gallery
Client can:View gallery, browse photos in lightbox, download individual or all as ZIP

Complete File Journey

1. Import RAWs → RAWS-FOR AUTOMATION\{Code} - Client\
2. Green-label keepers in Lightroom (XMP sidecars updated)
3. Watcher copies green RAWs + XMP → CULLED\{Code} - Client-FOR-IMAGEN\
4. Upload FOR-IMAGEN folder to Imagen AI
5. Imagen writes edits back to XMP sidecars
6. Watcher copies edited RAWs + XMP → LR-AUTO-IMPORT\
7. Lightroom auto-imports edited RAWs
8. Export JPGs from Lightroom → EXPORTS-FOR AUTOMATION\{Code} - Client-Exports\
9. Watcher uploads JPGs → WordPress Gallery
10. Client receives email with gallery link Delivered!
