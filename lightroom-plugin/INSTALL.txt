Tweller Flow — Lightroom Classic Export Plugin
================================================

INSTALL:
1. Copy the "TwellerFlow.lrplugin" folder to your Lightroom plugins folder:
   - Windows: C:\Users\{YourName}\AppData\Roaming\Adobe\Lightroom\Modules\
   - Or any folder you choose

2. In Lightroom Classic:
   - Go to File > Plug-in Manager
   - Click "Add" and navigate to the TwellerFlow.lrplugin folder
   - Click "Done"

3. To export photos:
   - Select the photos you want to deliver
   - File > Export (or Ctrl+Shift+E)
   - Choose "Tweller Flow Gallery" from the export dropdown (top-left)
   - Enter your website URL and API key
   - Enter the session tracking code (e.g., A1B2C3)
   - Choose a local export folder (optional)
   - Set a gallery password (optional)
   - Click "Export"

The plugin will:
- Export photos as JPEG to your local folder
- Upload each photo to your WordPress gallery
- Auto-advance the session to "delivered" (optional)
- The client will see the gallery on their tracking page

SETTINGS:
- Website URL: Your WordPress site (e.g., https://twellerstudios.com)
- API Key: From WordPress > Tweller Flow > Settings > Automation API Key
- Session Code: The 6-character tracking code for this session
- Local Folder: Where to save copies on your PC
- Gallery Password: Optional password clients need to enter to view photos


Tweller Auto Organizer — Session-Based Import Organization
==========================================================

INSTALL:
1. Copy "TwellerAutoOrganizer.lrplugin" to your Lightroom plugins folder
   (same location as TwellerFlow.lrplugin above)

2. In Lightroom Classic:
   - Go to File > Plug-in Manager
   - Click "Add" and navigate to the TwellerAutoOrganizer.lrplugin folder
   - Click "Done"

3. DISABLE Lightroom's built-in Auto Import:
   - Go to File > Auto Import Settings
   - UNCHECK "Enable Auto Import"
   - Click OK

4. Configure the Auto Organizer:
   - Go to Library > Plug-in Extras > Auto Organizer Settings
   - Set Watch Folder to your LR-AUTO-IMPORT path
     (e.g., T:\TWELLER STUDIOS\PHOTOGRAPHY\LR-AUTO-IMPORT)
   - Set Destination to where you want organized session folders
     (e.g., T:\TWELLER STUDIOS\PHOTOGRAPHY\EDITED CULLED AUTO IMPORTS)
   - Check "Enable background auto-organizer"
   - Click Save

HOW IT WORKS:
- The watcher copies Imagen-edited photos to LR-AUTO-IMPORT (flat)
- The watcher writes .session-tracking.json mapping files to sessions
- This plugin picks up the files and moves them into organized folders:
    {destination}/{session name} To Export/
- Photos are imported into your LR catalog in the correct session folder
- Collections are created: "Sessions To Export > {session} To Export"

You can also manually trigger organization:
  Library > Plug-in Extras > Organize Imports by Session
